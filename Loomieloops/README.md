# Loomieloops

Premium handmade crochet e-commerce for women and men.

## Run locally

```bash
npm install
npm run dev
```

Open **http://localhost:5180/** (Loomieloops uses port 5180 so it does not mix with other Vite apps on 5173).

Update the WhatsApp number in `src/data.ts` (`WHATSAPP`) before going live.
