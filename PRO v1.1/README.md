# ProStaff — Retail Staffing & Recruitment

Premium React website for **ProStafff Solution Private Limited**.

## Stack

- React + Vite
- Tailwind CSS v4
- Lucide icons
- Manrope (Google Fonts)

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Content updates

Edit `src/data/content.js` for copy, FAQs, role categories, images and testimonials.

To publish testimonials, add objects to the `testimonials` array:

```js
{ quote: '...', name: '...', role: '...', company: '...' }
```

## Notes

- Candidate application form is front-end only (success state simulated). Connect to your API or form backend when ready.
- No job listings, employer enquiry form or DigiRecruitx content.
