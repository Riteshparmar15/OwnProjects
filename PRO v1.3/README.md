# ProStafff Solution — Nomu-inspired homepage

React + Vite + Tailwind CSS + Framer Motion recreation of the Nomu visual language, powered by **ProStafff Solution** retail staffing content, plus the Luxury & International Retail Ecosystem logo marquee.

## Run (do not open index.html directly)

This is a Vite app — double-clicking `index.html` will not work in Chrome.

```bash
npm install
npm run dev
```

Chrome should open automatically at **http://localhost:5173/**

Or open manually:
- Local: http://localhost:5173/
- Network: use the Network URL printed in the terminal

## Stack

- React 19 + Vite 8
- Tailwind CSS 4 (`@tailwindcss/vite`)
- Framer Motion
- Lucide React (icons only where needed)

## Sections

1. Intro splash (`TALENT. READY.`) with staffing journey
2. Hero + “Ask ProStafff anything” intake interface
3. Luxury & International Retail Ecosystem marquee (IN / UAE)
4. About, festive promo, capabilities grid
5. Dark staffing ops + animated metrics
6. Interactive hiring comparison
7. Retail roles + job openings filters
8. FAQ accordion
9. Closing statements + contact forms + large footer

Content sourced from the ProStafff screencapture / live site. Brand logos mark retail houses whose stores we staff nationally and internationally.
